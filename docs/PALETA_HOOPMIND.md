# Identidad visual HoopMind

Colores medidos sobre el logo (`img/logo_hoopmind.jpeg`).

| Uso | Nombre | Hex |
|---|---|---|
| Fondo | Crema | `#F8F5E4` |
| Principal | Azul acero | `#174D75` |
| Texto y contraste | Granate casi negro | `#21060A` |
| Apoyo | Azul muy claro | `#DCE7EF` |
| Apoyo | Granate muy claro | `#E8D9DC` |

Tipografía: **Montserrat** (gratis en Google Fonts) para títulos en mayúsculas y cabeceras de tabla; Arial para el texto corrido. Estilo plano y sobrio, sin sombras.
Gantt: Big Data = azul acero, IA = granate, Informe = azul claro, Gestión = gris rosado.
Si Word no tiene Montserrat instalada, mostrará otra fuente: instálala o usa el PDF.
