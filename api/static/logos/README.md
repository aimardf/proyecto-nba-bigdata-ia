# Escudos de equipos (opcional)

La página usa por defecto una "camiseta" con las siglas del equipo. Si dejas aquí un archivo `<id>.png` (el id del equipo es el
que sale en `/equipos`, por ejemplo `1610612747.png`), la página lo mostrará en lugar de las siglas.

Los logotipos de los equipos de la NBA son marcas registradas, por eso el repositorio no los incluye. Si decides usarlos,
aporta tú los archivos y cita la fuente y el uso (educativo) en el apartado legal del informe.
